  - [x] Transcribe the assignment order of `hmm-param.lsh:142-215` into a per-array statement of the result: which entries are copied, halved, or drawn, and which assignments later ones overwrite
    > **Note:** `s` = `state-n`, `p` = the new state at index `S` (old size); `T`, `O` old, `T'`, `O'` new; later assignments overwrite earlier ones.
    > **`init'`:** `init'[i] = state_p[i]` for uninvolved `i` (`:172`, goal 2's defect); `init'[s] = init'[p] = ½·init[s]` (`:179-180`).
    > **`T'`:** the S×S block is copied first. Inbound, for every `j` *including* `s`: `T'[j,s] = T'[j,p] = ½·T[j,s]` (`:184-185`). Outbound: `T'[p,j] = T[s,j]`, **unhalved** (`:194`), so for `j ≠ s` the partner's row is an exact copy of `s`'s. Self-loops: `T'[p,s] = T'[p,p] = ½·T[s,s]` (`:203-204`), overwriting `:194`'s unhalved `T'[p,s]`. Rows `s` and `p` each sum to one, and every other row keeps `T'[j,s] + T'[j,p] = T[j,s]`.
    > **`O'`:** the S×S block is copied first. Inbound: `O'[j,p] = O[j,s]` for every `j` (`:187`); for `j ≠ s` that copy is final and `O'[j,s]` keeps its old value. Every fibre *leaving* `s` or `p` is drawn at noise 0.1, overwriting `:187`'s copy at `O'[s,p]`. That is `2S + 2` draws in the order `(s,0) (p,0) (s,1) (p,1) … (s,S-1) (p,S-1) (s,p) (p,p)`.
    > **`state_p`, `state_entropies`:** left as zero arrays; computed rather than stored under ADR 0017, so this dissolves.
    > **Two consequences.** Emissions alone break the symmetry between `s` and `p`, since inbound fibres are copies and outbound rows are identical for `j ≠ s`; revision 03's saddle finding makes the draw necessary rather than decorative. And every outbound fibre of both states can emit `begin` (~1/6 of its mass on the fixture alphabet), which is the input goal 4's δ-seeding case needs.

- [x] Decide how the split twins stop being identical (axis 2)
  > **Done:** ADR 0022 §§2-5. Arcs into the split state are perturbed per predecessor at `w = 0.01`, the twin taking the remainder. Every emission fibre is copied, then fibres on live outbound arcs get a 1% `rand_p_vector` mixture on every split. The minimum EM budget after a split is required, and its size is left to goal 6 and the search loop. Split trials report unrounded data description length beside the total.
  > **Note:** This is a design choice, not a defect. Lush breaks the symmetry by redrawing every outbound emission fibre of both twins near-uniform at noise 0.1 (`:190-207`). That discards what the split state had learned about its outbound emissions, and it is the loss of learning the user's first answer under goal 2 was concerned about.
  > **Q:** Where should the small symmetry-breaking perturbation go: outbound emissions only, or the twins' outbound transition rows as well?
  > **A:** Neither: on transitions **into** the split state. The twins stay identical in their outbound values but are not equally likely to be entered. Each predecessor `j` gets its **own** perturbation of the halving, e.g. `T[1,·] = [0.2, 0.5, 0.3]` becomes `[0.099, 0.5, 0.3, 0.101]`, and state 2's row gets a different split of its `T[2,0]`. The twin is appended last.
  > **A (continued):** Output probabilities are neither split nor perturbed, inbound or outbound: every emission fibre is copied to the twin as it is.
  > **Q:** Splitting the one-state model gives a two-state model equivalent to it, which inbound perturbation cannot break. Should the first split get an exception (a small outbound emission perturbation), should the search start from two states, or should this stay open until it is measured?
  > **A:** Leave it open and settle it by measurement. The user does not expect it to matter: the degenerate two-state model has the same data cost as the one-state model and more parameters, so MDL never selects it as the final result, and the next split from it is expected to break the symmetry.
  > **Note:** Lush's search supports the first half of that argument. `suggest-split` and `suggest-move` (`hmm-trainer.lsh:773-841`, `:952-`) adopt the best-scoring candidate unconditionally: `best-total-dl` starts at `1e100` and is never compared with the incumbent's. So a non-improving model does become the base for the next move, and MDL picks among the saved models. Two things remain to measure. First, from the degenerate model, `suggest-move`'s merge back to one state may outscore every split, so the search would cycle between one and two states. Second, the argument above suggests the next split is still degenerate. If emissions are never perturbed, every model reached from the one-state model has identical fibres everywhere and is equivalent to it, whatever the transitions. Inbound perturbation separates twins by predecessor, which helps only when the predecessors *emit* differently. The only remaining asymmetry is the per-record first-step transient where `init` differs from the chain's stationary distribution, and whether EM amplifies it is empirical. Also note that `core.md` describes the port's planned acceptance rule as comparing each candidate against the incumbent, which would reject the degenerate split outright. That interaction belongs to the master plan's loop-design subgoal.
  > **Q:** Can a degenerate two-state model make the search cycle, merging back to one state because that costs fewer parameters?
  > **A:** No. MDL adds the data description length to the model's, and the one-state model underfits badly, so a model that really has more states wins despite its larger parameter cost.
  - [x] Establish whether independent per-predecessor inbound perturbations break the symmetry under EM, analytically and on constructed cases, including the one-state start model, where the split state's only predecessor is itself
    > **Note:** First probe, not the arm comparison (scratchpad scripts, `set02a_200` corpus as one record, splits with per-predecessor inbound perturbation of width 0.1 and every fibre copied). **It overturns the prediction in the note above that splits from one state stay degenerate.** Splitting the one-state fixture and converging EM made the twins diverge fully (max fibre gap 1.0). Data bits fell from 3139 to 2341, and the total description length from 3198 to 2435. The result was identical across three seeds, so EM amplifies whatever tiny asymmetry exists, and nothing needed an emission perturbation. Splitting the trained two-state model's content state, which has two predecessors with different perturbations, diverged too: fibre gap 1.6e-3 after 1 cycle, 0.63 after 20, 0.76 at convergence after 90 cycles, identically on `python` and `cython`. **What stays degenerate is a state with a single live predecessor.** The two-state model's boundary state is entered only from the content state, and splitting it left the twins bit-identical even after 1000 forced cycles. The entry ratio between the twins is then constant, as the analysis predicts. Such a split can only lose on description length, so it is a wasted trial rather than a hazard, but the measurement should count how often it arises. The one-state cycling concern in the note above is also moot: the diverged two-state model beats the one-state model by 763 bits in total.
    > **Note:** Constructed cases (scratchpad, synthetic 4-symbol data sampled from sharp models, EM with the stop rule disabled; gap = max absolute difference between the twins' outbound rows and fibres) **correct two claims in the probe note above**.
    > **Analysis.** Twins with identical outbound rows and fibres have identical backward variables, so EM can pull them apart only through the entry ratio `α_t(s)/α_t(p)`. That ratio varies over time only if the twins have more than one *distinct* predecessor row with a live arc into them. The twins' own rows are identical copies and count as one, so the one-state model is a single-predecessor case. Otherwise the ratio is constant and the symmetric point is a fixed point of EM in exact arithmetic.
    > **Several predecessors: the perturbation carries a real signal.** Gap by cycle 1/10/50/100/400 = `8e-4 / 9e-3 / 1e-1 / 4e-1 / 4e-1`. With exact halves (`w = 0`) it stays `0` for 400 cycles, so the perturbation is necessary, not decorative.
    > **One state: the divergence is floating-point rounding, magnified.** With `init` matched to the entry ratio, which removes the first-step transient, the gap is `2e-15` (pure rounding) at cycle 1, `5e-11` at 50, `3e-3` at 100, `1.0` at 200. With `w = 0` it stays exactly `0`. So the symmetric point is **unstable**: the perturbation seeds the break only through its rounding footprint, and it takes about 100 cycles to show. The probe's claim that "EM amplifies the first-step transient" was wrong: removing the transient changed nothing.
    > **Single predecessor, stochastic outbound: rounding grows far more slowly.** `6e-16` at cycle 1, `9e-14` at 200, `6e-11` at 400, where `run-converge`'s stop rule would long since have fired. So the probe's "stays exactly degenerate on any corpus" was too strong. It is degenerate to first order, and its *bit-exact* zero on the fixture's boundary state came from that state's **deterministic** outbound behaviour (always to state 0, always `begin`), whose point-mass estimates no reweighting can move.
    > **Consequence for the decision.** Where the twins have one distinct predecessor row, including every split from the one-state model the search starts with, the inbound design breaks symmetry only through amplified rounding. That depends on evaluation order, so it is not guaranteed across hosts or the `torch` tolerance, and it depends on EM running long enough. It happened to work on `set02a_200` in 60 cycles. The measurement should test a deliberate seed for exactly those splits (a small outbound emission perturbation) against relying on rounding.
