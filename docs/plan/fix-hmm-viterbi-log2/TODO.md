- [x] Choose the fix and state which `log2` is contract
  > **Q:** Which fix: (a), one numpy table, with the contract "every arc cost and the seed are `bits()` on the host (numpy's `log2`), and kernels perform only `+` and `<`", or (b), libm everywhere?
  > **A:** (a), the numpy table.
  > **Done:** **The contract is numpy's `log2`, evaluated on the host through `bits()`, for every arc cost and for the seed; a kernel performs only `+` and `<` on the resulting bits.** Phases 2 and 3 adopt phase 4's host table: `_decode` receives `arc_bits (S, S, U)` over `U = np.unique(codes)`, the re-indexed `sym`, and `seed = bits(init_p)`. The public `_viterbi(init_state_p, transition_p, output_p, codes)` signature is unchanged, as ADR 0003 requires. `_viterbi.py` is not edited, so `FORMALIZATION.md` stays fresh and goal 3's chain is `.pyx` → `cpu_parallel` → `cuda`, re-stamped one link at a time.
  > **Note:** **numpy's `log2` is a function of the value alone on a given host**, which is the premise (a) rests on. Measured 2026-09-14 over 1,000,003 kernel-shaped inputs, numpy 2.4.6 dispatching `X86_V4`: 0 differences between one long contiguous call and 0-d scalar calls, 49-element (7×7) calls, call lengths 1-17, a `::3` strided view, a transposed view, or a shifted alignment. So phase 1's per-position `(S, S)` and a per-record `(S, S, U)` table produce identical bits.
  > **Note:** **the agreement this buys is within one host, not across hosts.** numpy's result depends on its SIMD dispatch (`X86_V3`, `X86_V4`, ARM) and libm's would depend on the glibc version, so neither option could promise bit-identical output across machines. `FORMALIZATION.md` must state the scope as "all backends agree on the same host", not as cross-machine reproducibility.
  > **Note:** **the table works only because Viterbi's recurrence is pure min-plus after the logarithms.** Revision 03's forward pass needs `log`/`exp` inside the recurrence for log-sum-exp, which no host table can supply, so the question returns there in another form. This decision covers the decode only.
