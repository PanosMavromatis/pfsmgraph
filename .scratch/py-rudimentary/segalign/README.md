# SegAlign: Sequence Alignment for Computational Music Theory

A modular, research-focused library for symbolic music analysis and autonomous music understanding using sequence alignment algorithms.

## Overview

SEGAlign adapts sequence alignment concepts from computational biology to musical applications, providing tools for analyzing symbolic music representations and musical token sequences.

## Features

- Modular sequence alignment algorithms (SS-2, Smith-Waterman variants, T-Coffee adaptations)
- Symbolic music processing capabilities
- GPU acceleration support
- Research-friendly API design
